## ✨ 🌟 About the Project

Campus Crush AI is a **next-generation university-exclusive platform** that combines:

💘 Dating + 🤝 Networking + 🧠 AI Coaching + 🗺️ Campus Intelligence  

> ⚡ Built to simulate real-world social interaction inside a campus ecosystem.

---

## 🚀 🔥 Core Features

### 💘 Smart Dating System
- Tinder-style swipe cards
- Super Like ⭐ + Undo ↩️
- 💖 “It’s a Match” full-screen animation
- Profile strength meter with live scoring

### 💬 Realtime Communication
- Chat with typing indicator & seen status
- Emoji reactions ❤️😂🔥
- Voice notes + image sharing
- Socket.IO powered real-time updates

### 📞 Voice & Video Calling
- WebRTC UI
- Twilio token integration
- Incoming call screen + controls

### 🧠 AI Relationship Coach
- Smart conversation suggestions
- Flirting assistant 😏
- Dating advice generator

### 🗺️ Campus Map System
- Location-based student discovery
- Nearby colleges auto-detection
- Cafes ☕, gyms 💪, hotspots 📍
- OpenStreetMap + Leaflet integration

### 🛡️ Verification System
- Email OTP authentication
- Student ID upload
- Selfie verification system

### 💳 Payments & Premium
- Razorpay + Stripe integration
- Subscription plans
- Premium feature unlock system
